# Hearth CRM - Real Estate Agency CRM

A lightweight, zero-dependency, and responsive client and deal pipeline management CRM tailored for real estate agencies and independent property brokers.

## 🌟 Key Features

- **📊 Executive Dashboard**: Instant visibility into key metrics:
  - Expected vs. Earned commissions
  - Collected vs. Outstanding payments
  - Lead-to-close conversion rate
  - Visual breakdown by month, stage, locality, and agent performance
- **📋 Visual Pipeline (Kanban)**: Drag-and-drop lead cards across deal stages (`New lead`, `Site visit`, `Negotiation`, `Closed`).
- **🤝 Contacts & Lead Management**: Comprehensive profiles tracking client type (Buyer, Renter, Seller), requirements, budget, preferred area, and assigned agent.
- **🏠 Property Listings & Smart Matching**: Automatically pairs buyers/renters with matching available inventory within budget and preferred localities.
- **📄 Offer Sheet Generator**: Quickly build tailored, professional offer summaries with token amount and brokerage calculations ready to copy or apply directly.
- **⏰ Follow-ups & Task Reminders**: Schedule calls, site visits, and paperwork tasks with overdue tracking.
- **💰 Commission & Receipt Tracker**: Track percentage rates, advances, and pending dues per deal.
- **🌗 Dark / Light Mode**: Seamless theme switching with system preference detection.
- **📥 CSV Export**: One-click data export ready for spreadsheet analysis.
- **💾 Local Persistence**: Works entirely in the browser with `localStorage` persistence and sensible seed data.

## 🚀 Getting Started

Since Hearth CRM is built with vanilla HTML, CSS, and modern JavaScript without build steps or external dependencies:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/soumyab92/real-estate-agency-crm.git
   ```
2. Open `index.html` directly in any modern web browser:
   - Double-click `index.html`, or
   - Serve using any static server (e.g. `npx serve .` or VS Code Live Server).

## 💻 Tech Stack

- **HTML5 & Vanilla JavaScript**: Clean, fast, zero runtime or build dependencies.
- **Modern CSS**: Custom properties (CSS variables), CSS Grid, Flexbox, responsive layouts, and native modal dialogs.
- **Typography**: Fraunces & Instrument Sans (via Google Fonts).
